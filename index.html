The same tricks LeakHunter uses for good, attackers use against you. Paste any message, link or file name you received. X-Ray finds invisible tracking characters, look-alike letters from other alphabets, reversed text that disguises file types, and links that hide where they really go.

Always-on owner recognitionSentinel

Sentinel learns how each owner moves the mouse, clicks and types. While you use AEGIS it keeps checking who is at the keyboard. An owner is greeted by name; a stranger is detected and the site locks until an owner proves who they are with a fingerprint or their typing rhythm.

05

Under the hoodHow it works

All four engines run entirely in the browser. Nothing you type or paste leaves the device.

KeyPrint

  1. Capture. Every key press is timestamped with sub-millisecond precision: dwell time (key held) and flight time (gap to the next key).
  2. Learn. Five clean attempts build a statistical model: the mean and spread of every timing feature.
  3. Calibrate. Leave-one-out testing measures how much you vary from yourself, and sets a personal acceptance threshold.
  4. Verify. A challenger's rhythm is scored with a scaled Manhattan distance. Right password, wrong rhythm: denied.

LeakHunter

  1. Encode. The recipient's name and ID become bytes, protected by a CRC-8 checksum.
  2. Hide. Each pair of bits maps to one of four zero-width Unicode characters, which render as nothing.
  3. Spread. The signature is woven in several times across the message, so even a partial copy still carries it.
  4. Back-up layer. The copy number is also written with look-alike letters from the Cyrillic alphabet, so the trace survives apps that delete invisible characters.
  5. Trace. Pasted text is scanned for both layers, decoded, and verified by checksum before a name is shown.

X-Ray

  1. Invisible characters. Zero-width and other invisible code points are counted, located, and decoded when they carry an AEGIS signature.
  2. Homoglyphs. Every word is checked for letters from more than one alphabet, such as a Cyrillic "а" hiding inside a Latin "apple".
  3. Bidirectional overrides. Right-to-left override characters that make "exe.pdf" display as "fdp.exe" are flagged.
  4. Links. URLs are checked for punycode, raw IP addresses, shorteners, look-alike brand names and "@" tricks.

Sentinel

  1. Observe. Mouse speed, path curvature, straightness, pauses, click hold time and typing gaps are measured over a sliding 12-second window.
  2. Learn. A short calibration (targets to click and a sentence to type) builds a statistical profile for each owner.
  3. Recognize. Every second the live window is compared with every owner; the closest match above the threshold is named.
  4. Lock. When no owner matches for five seconds in a row, the site locks. Unlocking needs a passkey (fingerprint or face on the device) or the owner's typing rhythm.
